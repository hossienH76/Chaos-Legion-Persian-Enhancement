# Chaos Legion Persian & Enhancement Patch
فارسی‌ساز و بهبودهای گرافیکی بازی Chaos Legion

این پروژه با هدف بهبود تجربه بازی Chaos Legion در نسخه PC و ارائه تجربه‌ای کامل‌تر برای بازیکنان فارسی‌زبان توسعه داده شده است.

✨ ویژگی‌ها و تغییرات

- پشتیبانی از مانیتورهای عریض (Widescreen Support): اصلاح نمایش بازی برای سازگاری با مانیتورهای عریض و نسبت تصویر 16:9.
- افزایش کیفیت میان‌پرده‌ها (Cutscene Enhancement): بهبود کیفیت تصویری کات‌سین‌های بازی.
- زیرنویس فارسی (Persian Subtitles): اضافه‌شدن زیرنویس فارسی به میان‌پرده‌های سینمایی بازی.
- رفع مشکلات بافت‌ها (Texture Fixes): اصلاح خطاها و مشکلات مربوط به نمایش تکسچرهای بازی.
- فارسی‌سازی متون داستانی (Story Text Localization): ترجمه و فارسی‌سازی متون داستانی که در ابتدای برخی مراحل نمایش داده می‌شوند.
